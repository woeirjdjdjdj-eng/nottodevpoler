|คำสั่ง                       |ใครใช้ได้                |ทำอะไร              |

|`!credit`                 |ทุกคน                   |เช็คยอดเครดิตตัวเอง   |

|`!addcredit @user จำนวน`   |แอดมิน (Manage Server)  |เติมเครดิตให้ลูกค้า     |
|`!removecredit @user จำนวน`|แอดมิน (Manage Server)  |หักเครดิตออก         |
